# Google Business Profile — what to enter

Everything below is ready to paste. Written to match smoald.com so the profile
and the site agree; Google cross-checks them, and a mismatch weakens both.

---

## Business name

```
SMOALD
```

Your trading name and nothing else. Do **not** write "SMOALD Web Design
Lichfield" — keyword-stuffed names are the most common reason a profile gets
suspended, and the location is set separately anyway.

---

## Categories

```
Software company

```

## Location

When asked *"Do you want to add a location customers can visit?"* → **No**

That makes you a **service-area business**. Google still asks for an address to
verify you, but does not publish it.

**Service area** — add these:

```
Lichfield
Burntwood
Tamworth
Rugeley
Sutton Coldfield
Cannock
Burton upon Trent
```

Add Birmingham only if you would genuinely travel there. Listing somewhere you
would not go weakens the local signal for everywhere else.

## Hours

Set real hours you will actually answer the phone. "Open 24 hours" reads as
untrue and helps nobody. If you would rather not commit, leave hours off — it
is allowed.

---

## Photos

Google favours profiles with photos, and there is no requirement for them to be
of an office.

- Screenshots of sites you have built (the honey farm and ThaiBridge both look
  good on a phone)
- The SMOALD logo as the profile picture
- `assets/og-default.png` works as a cover image

## After verification

1. **Add the profile link to smoald.com** — tell me and I will add it to the
